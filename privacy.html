개인정보처리방침

시행일: 2026년 11월 7일

1. 목적

content-auto는 운영자 본인의 YouTube·Instagram·Threads 계정에 운영자가 직접 만든 콘텐츠를 게시하기 위한 개인용 도구이며, 다른 사용자에게 서비스를 제공하지 않습니다.

2. 수집하는 정보

제3자의 개인정보를 수집하지 않습니다. 운영자 본인 계정의 접근 토큰만 운영자의 PC에 저장하며, 외부 서버로 전송하거나 공유하지 않습니다.

3. Google 사용자 데이터의 이용

YouTube Data API는 운영자 본인 채널에 동영상을 업로드하는 용도로만 사용합니다. Google 사용자 데이터를 판매·광고·분석 목적으로 사용하거나 제3자에게 제공하지 않습니다. 본 도구의 Google API 정보 이용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다. YouTube 이용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.

4. 보관 및 삭제

토큰은 운영자 PC에만 보관되며, 운영자는 언제든 Google 계정 설정(myaccount.google.com/permissions)에서 접근 권한을 철회할 수 있습니다.
